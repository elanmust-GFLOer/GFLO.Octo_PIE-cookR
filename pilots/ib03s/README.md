# IB-03S Multi-Issuer Gateway Integration & Failure-Mode Gate
LAB candidate only — PRODUCTION BLOCK. A new IB-03Q-compatible gateway validates Ed25519 admission request with a shared PostgreSQL public-key registry and atomically claims the nonce via IB-03R, without local filesystem fallback. Negative tests cover forged transport, replay, lost database connectivity and revoked public keys.

**Limitations:** this test deliberately uses invalid SIWE downstream and thus does not establish successful session issuance across multiple real issuer replicas. It does not replace IB-03Q gateway in a deployed service, prove multi-host availability, replica lag, DB failover or network partitions. IB-03R key epoch is NOT included in the signed IB-03Q envelope, so same-public-key reactivation could allow old signed requests if nonce unspent: **ROTATION BINDING BLOCKER**. A compromised shared DB role can consume nonce without authenticating a signature. DB owner is a trusted root. No production merge, rollout, Supabase, Lovable, wallet writes.
